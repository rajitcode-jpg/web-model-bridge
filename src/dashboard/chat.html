Welcome to Web Model Bridge Chat Studio!

This hackathon project connects your local apps to web AI models (Google Gemini, ChatGPT, Claude, DeepSeek, and more) with real browser typing, multimodal uploads, and streaming.

• Select any of the 9 providers from the sidebar dropdown (Google Gemini, ChatGPT, Claude, DeepSeek, Grok, Kimi, Qwen, GLM, Perplexity).
• Attach any video, audio, image, or document file using the 📎 button or drag-and-drop.
